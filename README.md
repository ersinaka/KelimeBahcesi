# Kelime Bahçesi

3–8 yaş dil gelişimi için Türkçe tarayıcı oyunu. Vite + React + TypeScript. Veriler yalnızca `localStorage` içinde tutulur.

## Çalıştırma

```bash
npm install
npm run dev
```

## Adımlar

1. ✅ İskelet, tema, veri, Zustand store
2. ✅ Profil seçimi, ana menü
3. Eşleştir + speechSynthesis
4. Bahçe ilerlemesi
5. Terapist paneli
6. Kategorile & Söyle
7. Dışa/içe aktarma, erişilebilirlik cila
